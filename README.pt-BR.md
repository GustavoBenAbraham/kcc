# KCC — Kindle Comic Converter

**Português** | [English / documentação original](README.md)

Apresentação em português deste fork. O KCC é um projeto de terceiros; os créditos e a documentação completa continuam no README original.

## Sobre

O Kindle Comic Converter prepara quadrinhos e mangás para leitores de tinta eletrônica, como Kindle e Kobo. Ajusta as imagens ao dispositivo e oferece opções de recorte, páginas duplas e formatos de saída.

O projeto tem interface gráfica e ferramentas de linha de comando, com instruções para Windows, macOS e Linux.

## Instalar e usar

Para versões prontas, consulte os [releases oficiais](https://github.com/ciromattia/kcc/releases). Escolha o arquivo correspondente ao sistema operacional e consulte o README original para compatibilidade do dispositivo e dos formatos.

Na interface, adicione os arquivos, selecione o perfil do leitor e converta. A compatibilidade e a forma de transferência variam por aparelho.

## Executar o código no Windows

Exemplo para o Prompt de Comando, conforme as instruções originais:

```bat
python -m venv venv
venv\Scripts\activate.bat
pip install --upgrade pip
pip install -r requirements.txt
python kcc.py
```

No macOS/Linux, use a ativação de ambiente apropriada e consulte as dependências na documentação original.

## Contexto deste fork

Este repositório mantém uma cópia do projeto original; esta apresentação não atribui a autoria do KCC ao proprietário do fork nem afirma contribuições ao código.
